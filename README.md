# Conlaude

Conlaude 是一个 Windows 本地桌面客户端，用来操作服务器 tmux 中持续运行的 Claude Code。它让中文输入、多行编辑、草稿和快捷键全部留在本地，只在点击发送时通过现有 SSH 连接一次性提交整段消息。

它不使用 `claude -p`，不使用 Claude Remote Control，不运行本地或远端 Web 服务，也不要求在 EC2 安全组开放新端口。

## 首次配置

新安装的服务器列表为空。先导入本机 OpenSSH 配置，或添加自己的服务器，再填写默认工作目录和 Claude 启动命令。已有用户升级时保留服务器、草稿和偏好；旧配置不会被删除，也不会再自动加入新安装。

远端助手位于 SSH 用户自己的 `~/.local/share/claude-local-bridge/bridge_agent.py`。

应用配置保存在 `%APPDATA%\Claude Local Bridge\config.json`，包含服务器、会话默认值和界面偏好，不应提交到仓库。根目录的 `config.example.json` 仅提供配置模板，可复制到上述位置后按需修改。

## 已实现功能

- 新会话可选择服务器、浏览远程文件夹或手动输入目录，直接设置 tmux 会话名；服务器行的“＋”会预选对应服务器。
- 重开应用恢复上次窗口尺寸、位置和最大化状态，适配显示器变化和 Windows 缩放。
- 远程文件面板：右上角打开侧栏后选择文件标签，按需浏览目录、筛选文件名和显示隐藏文件；简单编辑 1 MB 以内的 UTF-8 文本，Ctrl+S 保存，检测远端修改冲突。
- 文件栏顶部最右端的“目录侧栏”开关控制文件右侧目录；支持拖动调宽并记住偏好，窄栏使用同一开关临时浏览目录，不再保留单独的文件夹按钮。
- 服务器、文件夹和聊天支持同级拖动排序并自动保存；也可在聚焦行上按 `Alt+Shift+↑/↓` 调整。
- 右上角并排显示右侧栏与底部栏开关。再次点击右侧当前工具图标会收起侧栏；文件标签固定在顶部一行，目录可在文件右侧展开，编辑和保存位于底部；目录位置与各文件草稿独立保留。右键及常驻菜单支持下载、复制路径/名称、重新读取、定位目录和关闭标签。
- Windows 托盘可显示／隐藏窗口、新建聊天、打开服务器、设置或诊断，退出项为 `Exit`。
- 统一侧栏：按服务器和会话的实际工作目录组织项目，分别记住折叠状态；单击打开，支持中文标题与置顶。已打开会话的目录会保存，重启等待连接时仍能辨认项目。
- 按 `Ctrl+K` 搜索会话，`Enter` 打开首项，方向键选择结果；侧栏可筛选“运行中”和“待处理”会话，切换筛选不会改变当前会话和草稿。
- 跨服务器保留会话、草稿和阅读位置，重启恢复上次会话及其只读状态；在线连接的目标地址受保护，修改前需先断开本地连接。
- 本地 CodeMirror 多行编辑器、中文 IME、撤销重做、草稿和历史。
- 切换语言或发送快捷键时保留编辑器撤销历史；Shift+Tab 仅在本地输入框内切换 Claude 权限模式。
- 默认浅色界面，可切换深色或跟随系统；界面支持简体中文和 English 即时切换。
- Ctrl+Enter 整段发送，使用 bracketed paste 并过滤终端控制字符。
- 发送前检查 Claude 输入状态：目录信任等确认页会暂停发送并保留草稿，点击“查看终端”完成选择后自动恢复。
- 生成期间可点击“停止生成”；重新核实远端状态后发送 Esc，保留本地草稿。输入框下方常驻显示目标服务器和工作目录。
- 系统 OpenSSH + Windows ConPTY + tmux 原生交互链路。
- 对话旁可打开文件／终端侧栏，也可把终端放在底部；侧栏宽度、底部终端高度均可拖动调整。终端支持搜索、复制和直接控制。
- 从服务器 Claude JSONL 重建用户消息、回复、工具调用和工具结果。
- 隐藏 Claude 内部元数据，并用精确会话 ID 隔离应用创建的各个 transcript。
- tmux 会话发现、只读观察、连接、分离、创建、重命名和显式终止。
- SSH 断线自动退避重连；远端会话已结束时停止重连并显示原因。本地退出不会终止服务器 tmux。
- 对话记录连接可独立恢复，按已读取的位置继续同步；异常时显示提示并提供终端入口。中文与 emoji 使用连续 UTF-8 解码，避免网络分块导致乱码。
- 单文件上传上限 100 MB，显示文件名、大小、上传阶段和耗时；失败后可重新选择文件，成功后插入远程路径。
- 发送期间的继续编辑不会被清空；上传途中切换会话，文件路径仍归入原会话草稿。输入法确认候选词不会触发发送。
- 连接诊断逐项显示进度，失败时保留已完成结果；导出当前检查快照，无需重复连接，仅保留状态与故障类别。
- 后台会话需要确认、完成回复或连接失败时发送系统通知；点击通知可返回对应会话。
- 对话搜索按实际出现次数计数，可逐处导航和高亮。
- 对话左侧大纲按提问分轮显示等长短线；悬浮时短线形成跟随光标的波形，并预览加粗提问与模型回答。点击短线跳到该轮，向上阅读时新回复不会打断；键盘聚焦后可用方向键、Home／End 选择，Enter 跳转、Esc 关闭预览。
- 设置、系统托盘和外链确认。
- 沙箱 renderer、类型化最小 IPC、严格 CSP、主机密钥验证。

## 直接运行

当前发布版本为 **Conlaude 1.0.34**（Windows x64），新增文件栏内可选的目录侧栏，支持并排浏览、拖动调宽和偏好记忆，保留原整栏目录浏览及 1.0.33 已发布修复。直接运行便携版：

```powershell
& '.\dist\Conlaude-1.0.34\Conlaude-Portable-1.0.34-x64.exe'
```

- `dist/Conlaude-1.0.34/Conlaude-Setup-1.0.34-x64.exe`：安装版。
- `dist/Conlaude-1.0.34/Conlaude-Portable-1.0.34-x64.exe`：免安装便携版。
运行安装包或便携包无需安装项目开发依赖。

改名后继续使用原有 `Claude Local Bridge` 用户数据目录，保留服务器配置、草稿和界面偏好。

启动后：

1. 首次打开服务器库，可导入 SSH 配置或添加服务器；之后启动会恢复上次会话。
2. 例如连接 `my-server`：OpenSSH Host 填 `my-server`，Claude 启动命令填 `claude`。也支持可执行文件路径和其他 Bash 命令别名。
3. 点击服务器的“查看会话”，或左侧服务器卡片加载会话；文件夹整行可展开／收起，单击侧栏会话即可连接。点击“新会话”或服务器行的“＋”，选择服务器、浏览或手填工作目录、设置 tmux 名称，也可填写中文标题。首次浏览或创建会安装所需的远端连接组件。
4. 若提示 Claude 正在等待确认，点击“查看终端”，使用方向键选择后按 Enter。目录信任页默认可能选中“No, exit”，请先确认所选项。出现 Claude 输入框后，应用自动开放发送；在本地编辑器输入并按 `Ctrl+Enter` 发送。
5. 在左侧直接切换会话，或按 `Ctrl+K` 搜索已发现及最近使用的会话。右上角“会话操作”可改标题、置顶、只读观察或断开本地连接；终止远端会话仍需要输入完整标识确认。

连接失败和自动重连不会强制展开终端。右上角可分别开关右侧栏与底部栏；右边工具栏切换文件和终端，再次点击当前工具收起侧栏；文件标签栏左侧的文件夹按钮进入完整目录视图。`Ctrl+反引号` 按上次停靠位置展开／收起终端；拖动底部终端上边缘调整高度。

## 设置

设置按用途分为六类。每项提供影响范围说明，可按名称或用途搜索；改过的选项有标记，并可单独恢复默认。

| 分类       | 可调整内容                                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| 常规       | 语言、启动与关闭窗口行为、通知、外部链接确认                                                               |
| 外观       | 主题色、界面密度；独立的界面、回复、代码、终端字体及字号行距，终端光标；圆角、动画、边距和缓冲放在高级选项 |
| 侧栏与顶部 | 侧栏字号、服务器地址与会话数、顶部服务器名称及连接状态、视图按钮文字                                       |
| 对话       | 阅读宽度、消息间距、消息时间、执行详情默认展开、是否跟随最新消息                                           |
| 输入与发送 | 发送快捷键、字符上限、输入框字号、最大高度与折行、历史快捷键与保留条数                                     |
| 服务器     | 复用服务器编辑器修改连接及会话默认值，打开系统 OpenSSH 配置                                                |

普通偏好即时预览并自动保存，页脚显示保存状态；启动到托盘在下次启动时生效。每页可单独恢复默认值，保存失败时可重试或恢复已保存的偏好。数值会在本地校验，关闭设置不会撤销已经保存的修改。服务器配置和 OpenSSH 文件各自显式保存。旧版配置会自动升级到 v10，保留已有服务器和用户设置。

默认使用蓝色点缀与紧凑布局：服务器单行约 30 px，文件夹／会话行约 28 px；需要更宽松的点击区域时，可切换为“舒适”。服务器地址、会话数量、顶部服务器显示形式、连接状态及视图文字可分别调整。侧栏宽度和分屏比例继续通过拖动边界调整并保存；文件夹整行展开／收起，不显示小箭头。

服务器页选择的对象只用于编辑，不切换当前工作区。OpenSSH 文件单独保存；服务器导入集中在服务器页面。输入历史保留条数设为 0 会清除本地输入历史并停止保存，草稿保留。开启“跟随最新消息”后，向上阅读旧消息时仍会暂停跟随。

界面、回复和终端的字体选择器会读取 Windows 本机已安装字体，支持按名称搜索和手动刷新。新安装字体后点击刷新即可；内置预设仍可选。各处字体独立保存，终端建议选等宽字体。读取失败或配置中的字体已卸载时，会保留原选择并使用备用字体。

## 内容渲染

对话内容参考 [Codex 的 Markdown 渲染实现](https://github.com/openai/codex/blob/b8dceb0d4f29e49e73daa08f57fcf5181186f354/codex-rs/tui/src/markdown_render.rs)，采用紧凑标题与列表、右侧用户消息和可折叠的执行详情。用户输入保留原文，助手回复支持：

- 代码语言标签、语法高亮、复制源码和折行开关；长行默认横向滚动。
- 任务列表、保留对齐方式的表格、引用和数学公式。
- Mermaid 图表预览和源码切换，随明暗主题更新；无法绘制时保留源码。
- 可点击打开的远端文件路径与经应用确认的网页链接；远程图片以链接显示。

上述渲染功能已包含在最新版中。这是适配本项目的渲染实现，并非 Codex 桌面客户端源码或像素级复刻。

## 快捷键

输入 `/` 可补全常用 Claude 命令；执行后自动展开原生终端，完成或取消后可自行切换视图。空闲且输入框为空时，双击 Esc 打开回退入口。

| 快捷键         | 行为                                                                  |
| -------------- | --------------------------------------------------------------------- |
| `Ctrl+Enter`   | 发送本地消息                                                          |
| `Enter`        | 编辑器内换行                                                          |
| `↑` / `↓`      | 在文本边界浏览已发送消息历史，可在设置中改为 `Alt+↑` / `Alt+↓` 或关闭 |
| `Ctrl+反引号`  | 展开或收起真实终端                                                    |
| `Ctrl+Shift+P` | 聚焦本地编辑器                                                        |
| `Shift+Tab`    | 在本地输入框内切换 Claude 权限模式；其他控件保持反向焦点导航          |
| `Ctrl+F`       | 搜索当前对话，Enter / Shift+Enter 移到下一处／上一处                  |

## 开发与验证

项目保留完整源码、测试、构建资源和依赖锁文件。发布整理时已删除可重新生成的 `node_modules/`、`out/` 与测试输出。继续开发需要 Node.js 22 或更新版本，在项目根目录恢复依赖后启动：

```powershell
npm ci
npm run dev
```

常用验证与打包命令：

```powershell
npm run typecheck
npm run lint
npm run test:all
npm run build
npm run test:e2e:scenarios
npm run dist
npm run test:e2e
```

`npm run build` 生成 `out/`，界面测试前需先构建；`npm run pack` 生成当前版本的 `win-unpacked/`，打包程序测试前需先执行。`npm run dist` 生成安装版和便携版。测试报告、截图和隔离配置只保存在本机 `test-results/`、`playwright-report/` 与系统临时目录，不应提交到仓库。

端到端测试会读取本机的 `%APPDATA%/Claude Local Bridge/config.json` 或显式指定的隔离配置，可能连接真实服务器。运行前请确认目标服务器和清理范围；本机配置、日志和测试产物均已加入 `.gitignore`。

仅测试界面、不连接远端服务器：

```powershell
npm run test:e2e:scenarios
```

## 环境洁净规则

- `dist/` 只保留当前版本的安装包、便携包与校验记录；旧版本及临时预览包不保留。
- `src/`、`remote/`、`tests/`、`build/` 为源码、测试及构建输入；其中 `build/` 的图标和 Windows 品牌脚本不可作为缓存删除。
- 旧实施规划、迁移过程记录、评审截图及临时日志不随仓库发布。
- 不使用全局 npm 安装。
- 所有 JavaScript 包只在项目 `node_modules`。
- 构建与验证输出只在 `out`、`dist`、`test-results`、`playwright-report` 和 `coverage`。
- 远端助手只在 SSH 用户目录下，不使用 sudo。
- 当前依赖版本以 `package.json` 和 `package-lock.json` 为准。

## 安全说明

- 应用沿用所选 OpenSSH Host 的私钥、ProxyJump 和 known_hosts；不保存 SSH 凭据。
- 主机密钥变化会直接失败，不自动关闭验证。
- renderer 无 Node 权限，没有通用 `exec` 或文件系统 API。
- 远端 helper 不监听端口、不接受任意 shell 子命令。
- 终止 tmux 会话必须在应用内输入完整会话名确认。
- 提示词、Claude 回复和工具输出默认不写运行日志。

## 故障排查

先在应用左下角打开“连接诊断”。如果仍不能定位，检查所选 OpenSSH Host、远端 helper 版本和 `~/.local/share/claude-local-bridge/` 下的文件。

诊断详情只在本机显示。导出文件移除用户名、地址、路径及原始命令输出，保留检查状态、故障类别、时间和是否完成；诊断尚在运行时也可导出已完成项。
